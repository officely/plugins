# Officely

Officely is an enterprise workplace management platform. Connect it to Claude and ask about your offices the way you'd ask a colleague.

- Find and book a desk or meeting room, and change or cancel your bookings
- See who's in the office on a given day and where your team is sitting
- Look up places, floors, resources and booking rules
- For admins: manage people, teams, groups and workplace settings

Claude works as you, with the same access you have in Officely. Reading and changing are separate tools, so you can let Claude look things up freely and approve each change it makes.

The plugin includes the Officely MCP server and skills for bookings, booking rules, people and groups, and workplace inventory. The server has four tools: search finds the right Officely API operation, docs reads Officely's documentation, read looks things up, and write makes changes.

## Setup

Install the plugin, then sign in to Officely. In the Claude apps, connect Officely when Claude asks. In Claude Code, run `/mcp`, choose **plugin:officely:officely** and sign in in your browser. You sign in with your work Google or Microsoft account, or your company's single sign-on.
