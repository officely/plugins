# Officely plugins

Book desks and rooms, manage people and teams, and organise your workplaces from Claude Code or Codex.

**Claude Code**

```
/plugin marketplace add officely/plugins
/plugin install officely@officely
```

**Codex**

```
codex plugin marketplace add officely/plugins
```

Then install **Officely** from the marketplace. Setup guides for other AI tools are at [docs.officely.app](https://docs.officely.app/building/agent-workflow).
